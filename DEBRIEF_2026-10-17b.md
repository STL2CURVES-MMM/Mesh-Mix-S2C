### Fix 1 — crossing-wire spike absorption (committed `e384dce`, VERIFIED)

**Root cause confirmed:** `wire_cross.py` on face16.brep showed edges 3–6 forming
a tongue: UV goes in 0.3 mm and straight back. The `_absorb_self_crossing_strips`
candidate filter used `np.isin(keys, touch).all(1)` (all 3 vertices in target's
touch set). Spike triangle tips are interior to the source region — they never
touch the target. So the filter eliminated every candidate and `changed=False`.

**Fix:** Replace the all-3-vertices check with a shared-edge check:

```python
# Half-edge convention: nb[fi, e] is the neighbour across the edge
# from F[fi, e] to F[fi, (e+1)%3].  At least one of those two
# vertices must already be in the target's touch set.
dmax = np.maximum(dst, 0)
v0 = F[cand, edge].astype(np.int64) * nr + dmax
v1 = F[cand, (edge + 1) % 3].astype(np.int64) * nr + dmax
ok &= np.isin(v0, touch) | np.isin(v1, touch)
```

Also fixed `_rebuild_regions` to skip `prim.refit()` for freeform surfaces (they
have no `refit` method — latent crash that only became reachable once absorption
started firing). Also improved trial acceptance: only count *newly* invalid faces
against the trial (`new_bad = trial_bad - bad`), not pre-existing ones.

**Verified:** Zero regressions on all 30 suite models. Mount max gap 1.09→1.07 tol,
volume 0.9985→0.9993. Fix fires correctly: crossing regions [16,202] reduced to
[158] after repair, log says "Removed border strips that caused a self-crossing
CAD wire".

### Fix 2 — per-round ShapeFix_Face heal for UV gaps (committed `cd27158`, NOT YET SUITE-TESTED)

**Root cause confirmed:** Region 36 (large torus, 1740 triangles) has
`InvalidImbricationOfWires` — not from a spike, but from tiny UV pcurve endpoint
gaps (0.019–0.029, i.e. 0.28–0.42× tol) in the outer wire's V direction.

Diagnosis trace:
- `why_demoted2.py`: region 36 torus invalid every round, demoted to freeform
- `face_area.py` + `face_status.py`: `ClassifyWires=InvalidImbricationOfWires`
- `edge_status.py`: wire 0 has 3D gaps=True and 2D gaps=True, wires 1 and 2 ok
- Mesh loop topology: perfectly connected (0 gaps), so the problem is in CAD assembly
- `RegionGraph.region_loops[36]`: 3 loops, 8 chains, all chain-to-chain 3D gaps = 0
- UV pcurve inspection (orientation-corrected): wire 0 has e0→e1 UV gap = 0.019,
  loop closure gap = 0.029, both only in V direction

**Cause:** `FixAddPCurve` fits a pcurve by projecting interior edge points, and the
endpoint V values are off by ~0.02 from the true vertex projection. `FixShifted()`
only corrects 2π shifts — it can't close a 0.02 non-periodic gap. The outer wire's
polygon is therefore not closed in UV space, so `ClassifyWires` can't determine
which wires are holes vs outer boundary.

**Fix:** After `_settle_tolerances(f, tol)` for each still-invalid face, try
`ShapeFix_Face` with `precision=tol*0.5` (vs current end-of-run `tol*0.1`). Only
accept if result is valid and not blown up. This closes the UV gap without touching
3D geometry.

**Preliminary result:** On the mount, first-round demotions drop from 8 to 6.
Log: "6 surface(s) don't follow the mesh closely enough... 14 surface(s) rebuilt
as freeform... Repaired 1 of 1 remaining face(s)". Region 36 becomes valid.

**NOT VERIFIED on the full suite.** Must run before accepting.

## How the UV-gap diagnosis was done (for reference)

The chain of tools used to find that region 36's problem was a 0.019 UV gap:

1. `why_demoted2.py` → identified region 36 as invalid every round
2. `face_area.py MESH TOL Q 36 /tmp/mount_faces` → saved face36.brep
3. `face_status.py /tmp/mount_faces/face36.brep` → `ClassifyWires=InvalidImbricationOfWires`
4. `edge_status.py /tmp/mount_faces/face36.brep` → wire 0 has 3D+2D gaps
5. Python script tracing `RegionGraph.region_loops[36]` → 3 loops, all mesh gaps = 0
6. Python script reading pcurves with `BRepAdaptor_Curve2d` (orientation-corrected) →
   wire 0 e0→e1 UV gap = 0.019, loop closure = 0.029, both only in V
7. Projection via `ShapeAnalysis_Surface.ValueOfUV` confirmed correct vertex UV = (3.295, 1.374),
   pcurve endpoint = (3.295, 1.394) — a 0.019 V offset from `FixAddPCurve` imprecision
8. `ShapeFix_Face(prec=tol*0.5).Perform()` confirmed it fixes region 36 individually
